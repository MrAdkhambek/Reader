# Read3r 3.0 Redesign Implementation Plan

> **Superseded (2026-10-02)** by `docs/superpowers/specs/2026-10-02-three-library-design.md`: three Java libraries (`qr`, `passport`, `card`) with no shared artifact and no `-ktx` modules. Kept for history; do not execute.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the 4-module `{app, common, nfc, qr}` layout and its listener-based async API with 8 artifacts split by document type, a blocking Java core, and Kotlin `-ktx` modules exposing `Flow`.

**Architecture:** Java core libraries do blocking I/O and throw typed exceptions; they hold no threading policy. Kotlin `-ktx` modules wrap them in cold `Flow`s via `flowOn(Dispatchers.IO)`. A one-method `ApduChannel` interface replaces the concrete `IsoDep` dependency, making every reader testable by replaying recorded APDU transcripts. `:common` dissolves into `:mrz` (pure jar) and `:iso7816`.

**Tech Stack:** Java 17, Kotlin 2.0.21, kotlinx-coroutines 1.8.1, AGP 8.7.3, Gradle 8.10.2, JUnit 4.13.2, CameraX 1.3.4, ZXing 3.5.3.

**Spec:** `docs/superpowers/specs/2026-07-25-reader-api-redesign-design.md`

## Global Constraints

- Group: `com.adkhambek.reader`. Version: `3.0.0` (set in root `gradle.properties` as `VERSION_NAME`).
- `compileSdk = 34`, `minSdk = 21`, source/target `JavaVersion.VERSION_17`, Kotlin `jvmTarget = 17`.
- Every version goes in `gradle/libs.versions.toml`. No version literals in module build files.
- Every module applies a `read3r.*` convention plugin. No module declares `compileSdk`, `minSdk`, `compileOptions`, `lint` or `mavenPublishing` directly.
- `lint { warningsAsErrors = true }` everywhere. Suppressions must be commented where declared.
- Every published module has its own `gradle.properties` with `POM_ARTIFACT_ID`, `POM_NAME`, `POM_DESCRIPTION`. Maven Central rejects a POM without a name and description.
- **Indentation: Java and Kotlin source use TABS. Gradle `.kts` files use 4 spaces.** This matches the existing codebase — do not reformat.
- Every Java file starts with `/* SPDX-License-Identifier: Apache-2.0 */`.
- No library module performs network I/O.
- The build must be green (`./gradlew test lint`) at the end of every task.
- Run Gradle **without** `--offline`. Lint's analysis jars are not in the local cache and offline builds fail on `extractReleaseAnnotations`.

## Strangler ordering

Tasks 3–9 build the new modules **alongside** the existing `:common`, `:nfc` and `:qr`, which keep working and keep their tests passing. The sample app migrates in Task 10; the old modules are deleted in Task 11. This keeps the build green throughout at the cost of temporary duplication.

Task 2 is the exception: it is a true *move* out of `:nfc`, with `:nfc` gaining a dependency on the new `:iso7816`. Nothing is duplicated.

	/** Inverse of {@link #encode(byte[])}. Whitespace is ignored. */
	public static byte[] decode(String hex) {
		final StringBuilder clean = new StringBuilder(hex.length());
		for (int i = 0; i < hex.length(); ++i) {
			final char c = hex.charAt(i);
			if (c != ' ' && c != '\n' && c != '\t') clean.append(c);
		}
		if ((clean.length() & 1) != 0) {
			throw new IllegalArgumentException("odd-length hex: " + clean.length());
		}
		final byte[] out = new byte[clean.length() / 2];
		for (int i = 0; i < out.length; ++i) {
			out[i] = (byte) Integer.parseInt(clean.substring(i * 2, i * 2 + 2), 16);
		}
		return out;
	}

/* SPDX-License-Identifier: Apache-2.0 */
package com.adkhambek.reader.iso7816;

import java.io.Closeable;
import java.io.IOException;

/**
 * A bidirectional APDU pipe to a smart card.
 *
 * <p>The readers talk to this interface rather than to
 * {@link android.nfc.tech.IsoDep} directly, so a recorded card transcript can
 * be replayed in a unit test. {@link IsoDepChannel} is the production
 * implementation; {@code ReplayChannel} (test fixtures) is the test one.
 *
 * <p>Implementations carry no chaining logic — 61xx/6Cxx handling lives in
 * {@link Iso7816.StdTag}, which decorates a channel.
 */
public interface ApduChannel extends Closeable {

	/** Open the connection. Idempotent implementations are not required. */
	void connect() throws IOException;

	/** Send one command APDU and return the raw response, SW1 SW2 included. */
	byte[] transceive(byte[] apdu) throws IOException;

	/** Best-effort transceive timeout. Implementations may ignore this. */
	void setTimeout(int millis);
}
```

`iso7816/src/main/java/com/adkhambek/reader/iso7816/IsoDepChannel.java`:

/* SPDX-License-Identifier: Apache-2.0 */
package com.adkhambek.reader.iso7816;

import android.nfc.tech.IsoDep;

import java.io.IOException;

/** {@link ApduChannel} backed by an Android NFC ISO-DEP tag. */
public final class IsoDepChannel implements ApduChannel {

	private final IsoDep isoDep;

	public IsoDepChannel(IsoDep isoDep) {
		if (isoDep == null) throw new IllegalArgumentException("isoDep is null");
		this.isoDep = isoDep;
	}

	@Override
	public void connect() throws IOException {
		if (!isoDep.isConnected()) isoDep.connect();
	}

	@Override
	public byte[] transceive(byte[] apdu) throws IOException {
		return isoDep.transceive(apdu);
	}

	@Override
	public void setTimeout(int millis) {
		isoDep.setTimeout(millis);
	}

	@Override
	public void close() throws IOException {
		isoDep.close();
	}
}
```

```java
/* SPDX-License-Identifier: Apache-2.0 */
package com.adkhambek.reader.iso7816;

import java.io.IOException;
import java.util.ArrayDeque;
import java.util.Deque;

/**
 * An {@link ApduChannel} that replays a scripted exchange.
 *
 * <p>Build the script with alternating {@link #expect}/{@link #reply} calls,
 * run the reader against it, then call {@link #assertExhausted()}. An APDU that
 * does not match the next scripted request throws {@link AssertionError}, so a
 * reader that starts issuing an extra command fails loudly rather than
 * silently reading past the end of the script.
 *
 * <p>Transcripts captured from real cards are worth far more than invented
 * ones — an invented transcript encodes the implementation's assumptions
 * rather than the card's behaviour. Mark synthetic fixtures as such.
 */
public final class ReplayChannel implements ApduChannel {

	private static final class Exchange {
		final byte[] request;
		final byte[] response;

		Exchange(byte[] request, byte[] response) {
			this.request = request;
			this.response = response;
		}
	}

	private final Deque<Exchange> script = new ArrayDeque<>();
	private String pendingRequest;
	private boolean connected;
	private boolean closed;

	public ReplayChannel expect(String requestHex) {
		if (pendingRequest != null) {
			throw new IllegalStateException("expect() called twice without reply()");
		}
		pendingRequest = requestHex;
		return this;
	}

	public ReplayChannel reply(String responseHex) {
		if (pendingRequest == null) {
			throw new IllegalStateException("reply() called without expect()");
		}
		script.addLast(new Exchange(Hex.decode(pendingRequest), Hex.decode(responseHex)));
		pendingRequest = null;
		return this;
	}

	@Override
	public void connect() {
		connected = true;
	}

	@Override
	public byte[] transceive(byte[] apdu) throws IOException {
		if (closed) throw new IOException("channel closed");
		final Exchange next = script.pollFirst();
		if (next == null) {
			throw new AssertionError("unexpected APDU, script exhausted: " + Hex.encode(apdu));
		}
		if (!java.util.Arrays.equals(next.request, apdu)) {
			throw new AssertionError("unexpected APDU"
					+ "\n  expected: " + Hex.encode(next.request)
					+ "\n  actual:   " + Hex.encode(apdu));
		}
		return next.response;
	}

	@Override
	public void setTimeout(int millis) {
		// no-op
	}

	@Override
	public void close() {
		closed = true;
	}

	/** True once {@link #connect()} has been called. */
	public boolean isConnected() {
		return connected;
	}

	/** Fails if any scripted exchange was not consumed. */
	public void assertExhausted() {
		if (!script.isEmpty()) {
			throw new AssertionError(script.size() + " scripted exchange(s) unused, next: "
					+ Hex.encode(script.peekFirst().request));
		}
	}
}
```

/**
 * The fields carried by an ICAO 9303 machine-readable zone — immutable.

 * <p>This is what an MRZ contains and nothing more. Data that only exists on a
 * chip (DG11 personal details, DG12 document details, DG2 face image) belongs

 *
 * <p>Absent fields are null. Dates are {@code YYYY-MM-DD}, or the raw
 * {@code YYMMDD} field when it was not a valid date.

public final class MrzDocument {

	private final String documentType;
	private final String issuingCountry;
	private final String documentNumber;
	private final String lastName;
	private final String firstName;
	private final String sex;
	private final String nationality;
	private final String dateOfBirth;
	private final String dateOfExpiry;
	private final String personalNumber;
	private final String optionalData;
	private final String raw;

	private MrzDocument(Builder b) {
		this.documentType = b.documentType;
		this.issuingCountry = b.issuingCountry;
		this.documentNumber = b.documentNumber;
		this.lastName = b.lastName;
		this.firstName = b.firstName;
		this.sex = b.sex;
		this.nationality = b.nationality;
		this.dateOfBirth = b.dateOfBirth;
		this.dateOfExpiry = b.dateOfExpiry;
		this.personalNumber = b.personalNumber;
		this.optionalData = b.optionalData;
		this.raw = b.raw;
	}

	public String documentType() { return documentType; }

	public String issuingCountry() { return issuingCountry; }

	public String documentNumber() { return documentNumber; }

	public String lastName() { return lastName; }

	public String firstName() { return firstName; }

	public String sex() { return sex; }

	public String nationality() { return nationality; }

	public String dateOfBirth() { return dateOfBirth; }

	public String dateOfExpiry() { return dateOfExpiry; }

	public String personalNumber() { return personalNumber; }

	public String optionalData() { return optionalData; }

	/** The MRZ exactly as supplied, before field splitting. */
	public String raw() { return raw; }

	/** True when a document number was decoded — i.e. this really is an MRZ. */
	public boolean isPresent() { return documentNumber != null; }

	@Override
	public String toString() {
		// Deliberately redacted: an MRZ is high-value identity data and
		// toString() is what ends up in a log.
		return "MrzDocument[" + documentType + " " + issuingCountry
				+ (documentNumber == null ? "" : " ****") + "]";
	}

	public static final class Builder {
		private String documentType;
		private String issuingCountry;
		private String documentNumber;
		private String lastName;
		private String firstName;
		private String sex;
		private String nationality;
		private String dateOfBirth;
		private String dateOfExpiry;
		private String personalNumber;
		private String optionalData;
		private String raw;

		public Builder documentType(String v) { this.documentType = v; return this; }

		public Builder issuingCountry(String v) { this.issuingCountry = v; return this; }

		public Builder documentNumber(String v) { this.documentNumber = v; return this; }

		public Builder lastName(String v) { this.lastName = v; return this; }

		public Builder firstName(String v) { this.firstName = v; return this; }

		public Builder sex(String v) { this.sex = v; return this; }

		public Builder nationality(String v) { this.nationality = v; return this; }

		public Builder dateOfBirth(String v) { this.dateOfBirth = v; return this; }

		public Builder dateOfExpiry(String v) { this.dateOfExpiry = v; return this; }

		public Builder personalNumber(String v) { this.personalNumber = v; return this; }

		/** Set only if not already set — DG11's 5F10 must not overwrite DG1. */
		public Builder personalNumberIfAbsent(String v) {
			if (this.personalNumber == null) this.personalNumber = v;
			return this;
		}

		public Builder optionalData(String v) { this.optionalData = v; return this; }

		public Builder raw(String v) { this.raw = v; return this; }

/* SPDX-License-Identifier: Apache-2.0 */
package com.adkhambek.reader.emv;

import android.nfc.Tag;
import android.nfc.tech.IsoDep;

import androidx.annotation.WorkerThread;

import com.adkhambek.reader.iso7816.ApduChannel;
import com.adkhambek.reader.iso7816.Hex;
import com.adkhambek.reader.iso7816.Iso7816;
import com.adkhambek.reader.iso7816.IsoDepChannel;

import java.io.IOException;
import java.util.List;

/**
 * Reads an EMV contactless payment card.
 *
 * <p>Blocking and stateless — call it from a background thread. This class
 * holds no threading policy of its own: no executor, no handler, no callback
 * dispatch. For a coroutine API use {@code com.adkhambek.reader:emv-ktx},
 * which supplies the dispatcher.
 *
 * <p>An instance rather than static methods so it can be injected and faked.
 */
public final class EmvReader {

	private static final int TIMEOUT_MS = 5000;

	/** Read from an NFC tag. Convenience over {@link #read(ApduChannel)}. */
	@WorkerThread
	public EmvCard read(Tag tag) throws ReadException {
		if (tag == null) throw new IllegalArgumentException("tag is null");
		final IsoDep isoDep = IsoDep.get(tag);
		if (isoDep == null) {
			throw new UnsupportedDocumentException("card is not ISO-DEP");
		}
		final String uid = Hex.encode(tag.getId());
		return read(new IsoDepChannel(isoDep), uid);
	}

	/** Read from any APDU channel. This overload is what tests drive. */
	@WorkerThread
	public EmvCard read(ApduChannel channel) throws ReadException {
		return read(channel, "");
	}

	private EmvCard read(ApduChannel channel, String uid) throws ReadException {
		if (channel == null) throw new IllegalArgumentException("channel is null");
		final Iso7816.StdTag tag = new Iso7816.StdTag(channel);
		try {
			tag.connect();
			try {
				tag.setTimeout(TIMEOUT_MS);
			} catch (RuntimeException ignored) {
				// Best effort; some channels do not support timeouts.
			}
			final List<EmvApp> apps = Emv.readApps(tag);
			if (apps.isEmpty()) {
				throw new UnsupportedDocumentException("no EMV application found");
			}
			return new EmvCard(uid, apps);
		} catch (IOException e) {
			throw new CardLostException("card communication failed", e);
		} finally {
			try {
				tag.close();
			} catch (IOException ignored) {
				// Nothing useful to do; the read already succeeded or failed.
			}
		}
	}
}

package com.adkhambek.reader.emv.ktx

import android.nfc.Tag
import com.adkhambek.reader.emv.EmvCard
import com.adkhambek.reader.emv.EmvReader
import com.adkhambek.reader.iso7816.ApduChannel
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.flow.Flow
import kotlinx.coroutines.flow.flow
import kotlinx.coroutines.flow.flowOn

/**
 * Read [tag] as a cold [Flow] that emits one [EmvCard] and completes.
 *
 * Failures propagate through the Flow's own error channel — handle them with
 * `.catch { }`, not a result wrapper. Cancelling the collecting scope abandons
 * the read.
 *
 * The name is `cards`, not `read`, because a Kotlin extension can never shadow
 * a member with the same name and parameters: `EmvReader.read(Tag)` already
 * exists returning [EmvCard], so an extension of that name would silently
 * never be called.
 *
 * ```
 * reader.cards(tag)
 *     .catch { e -> _ui.value = UiState.Error(e) }
 *     .collect { _ui.value = UiState.Loaded(it) }
 * ```
 */
public fun EmvReader.cards(tag: Tag): Flow<EmvCard> = flow {
	emit(read(tag))
}.flowOn(Dispatchers.IO)

/** As [cards], against any APDU channel. */
public fun EmvReader.cards(channel: ApduChannel): Flow<EmvCard> = flow {
	emit(read(channel))
}.flowOn(Dispatchers.IO)

import android.nfc.Tag
import com.adkhambek.reader.emrtd.MrzKey
import com.adkhambek.reader.emrtd.Passport

 *
 * Failures arrive through the Flow's error channel. The one worth branching on

	emit(read(tag, key))
}.flowOn(Dispatchers.IO)

package com.adkhambek.reader.qr;

import java.util.Arrays;
import java.util.Objects;

/**
 * One successful decode, in pre-rotation image space.
 *
 * <p>Carries enough to draw the detection over a camera preview: the finder
 * pattern positions ZXing returned and the dimensions of the buffer they were
 * found in. Display rotation is deliberately absent — that is a CameraX
 * concept and belongs to the ktx layer.
 *
 * <p>QR codes always have at least three finder patterns, so {@code xs} and
 * {@code ys} are non-empty and of equal length.
 */
public record QrCode(
		String text,
		float[] xs,
		float[] ys,
		int imageWidth,
		int imageHeight
) {
	// A record compares arrays by identity, which would make two decodes of the
	// same code unequal. Compare by content.

	@Override
	public boolean equals(Object o) {
		if (this == o) return true;
		if (!(o instanceof QrCode other)) return false;
		return imageWidth == other.imageWidth
				&& imageHeight == other.imageHeight
				&& Objects.equals(text, other.text)
				&& Arrays.equals(xs, other.xs)
				&& Arrays.equals(ys, other.ys);
	}

	@Override
	public int hashCode() {
		return Objects.hash(text, Arrays.hashCode(xs), Arrays.hashCode(ys),
				imageWidth, imageHeight);
	}

	@Override
	public String toString() {
		return "QrCode[text=" + text + ", points=" + (xs == null ? 0 : xs.length)
				+ ", image=" + imageWidth + "x" + imageHeight + "]";
	}
}

- [ ] **Step 6: Write `QrDecoder`**

```java
/* SPDX-License-Identifier: Apache-2.0 */
package com.adkhambek.reader.qr;

import androidx.annotation.Nullable;

import com.google.zxing.BarcodeFormat;
import com.google.zxing.BinaryBitmap;
import com.google.zxing.DecodeHintType;
import com.google.zxing.MultiFormatReader;
import com.google.zxing.NotFoundException;
import com.google.zxing.PlanarYUVLuminanceSource;
import com.google.zxing.Result;
import com.google.zxing.ResultPoint;
import com.google.zxing.common.HybridBinarizer;

import java.util.EnumMap;
import java.util.EnumSet;
import java.util.Map;

/**
 * Decodes a QR code from a packed 8-bit luminance buffer.
 *
 * <p>A pure function over bytes: no camera, no threads, no callbacks. The
 * caller supplies the buffer — {@code com.adkhambek.reader:qr-ktx} does that
 * from CameraX frames, and a test can do it from a generated fixture.
 *
 * <p>Not thread-safe: the underlying ZXing reader carries state between calls.
 * Use one instance per analysis thread.
 */
public final class QrDecoder {

	private final MultiFormatReader reader;

	public QrDecoder() {
		reader = new MultiFormatReader();
		final Map<DecodeHintType, Object> hints = new EnumMap<>(DecodeHintType.class);
		hints.put(DecodeHintType.POSSIBLE_FORMATS, EnumSet.of(BarcodeFormat.QR_CODE));
		hints.put(DecodeHintType.TRY_HARDER, Boolean.TRUE);
		reader.setHints(hints);
	}

	/**
	 * @param luminance packed 8-bit luma, {@code width * height} bytes, row-major
	 * @return the decoded code, or null if this frame contained none
	 */
	@Nullable
	public QrCode decode(byte[] luminance, int width, int height) {
		if (luminance == null || width <= 0 || height <= 0) return null;
		if (luminance.length < width * height) return null;
		try {
			final PlanarYUVLuminanceSource src = new PlanarYUVLuminanceSource(
					luminance, width, height, 0, 0, width, height, false);
			final Result r = reader.decodeWithState(new BinaryBitmap(new HybridBinarizer(src)));
			return toQrCode(r, width, height);
		} catch (NotFoundException noCodeInThisFrame) {
			return null;
		} finally {
			reader.reset();
		}
	}

	private static QrCode toQrCode(Result r, int width, int height) {
		final ResultPoint[] points = r.getResultPoints();
		final int n = (points == null) ? 0 : points.length;
		final float[] xs = new float[n];
		final float[] ys = new float[n];
		for (int i = 0; i < n; ++i) {
			if (points[i] == null) continue;
			xs[i] = points[i].getX();
			ys[i] = points[i].getY();
		}
		return new QrCode(r.getText(), xs, ys, width, height);
	}
}
```

/* SPDX-License-Identifier: Apache-2.0 */
package com.adkhambek.reader.qr.ktx

import com.adkhambek.reader.mrz.Mrz
import com.adkhambek.reader.mrz.MrzDocument
import com.adkhambek.reader.mrz.MrzFormatException
import com.adkhambek.reader.qr.QrCode

/**
 * One decode, with the display rotation CameraX will apply.
 *
 * Rotation lives here rather than on [QrCode] because it is a CameraX concept;
 * the decoder itself knows nothing about display orientation.
 */
public data class QrScan(
	public val code: QrCode,
	public val rotationDegrees: Int,
) {
	/**
	 * The scanned text as an ICAO 9303 MRZ, or null if it is not one.
	 *
	 * Check digits are validated before decoding, so an arbitrary 88-character
	 * payload does not come back looking like an identity document.
	 */
	public fun mrz(): MrzDocument? {
		val stripped = code.text().filterNot { it == '\n' || it == '\r' || it == ' ' || it == '\t' }
		if (!Mrz.isValid(stripped)) return null
		return try {
			Mrz.decode(stripped).takeIf { it.isPresent }
		} catch (notAnMrz: MrzFormatException) {
			null
		}
	}
}

```kotlin
/* SPDX-License-Identifier: Apache-2.0 */
package com.adkhambek.reader.qr.ktx

import android.content.Context
import android.graphics.ImageFormat
import androidx.camera.core.CameraSelector
import androidx.camera.core.ImageAnalysis
import androidx.camera.core.ImageProxy
import androidx.camera.core.Preview
import androidx.camera.lifecycle.ProcessCameraProvider
import androidx.camera.view.PreviewView
import androidx.core.content.ContextCompat
import androidx.lifecycle.LifecycleOwner
import com.adkhambek.reader.qr.QrDecoder
import kotlinx.coroutines.channels.awaitClose
import kotlinx.coroutines.flow.Flow
import kotlinx.coroutines.flow.callbackFlow
import kotlinx.coroutines.suspendCancellableCoroutine
import java.nio.ByteBuffer
import java.util.concurrent.Executors
import kotlin.coroutines.resume
import kotlin.coroutines.resumeWithException

/**
 * CameraX-backed QR scanning.
 *
 * [codes] is a cold [Flow]: nothing binds the camera until it is collected, and
 * everything unbinds when collection stops. There is no start/stop/shutdown
 * lifecycle to manage and no listener to leak — cancelling the collecting scope
 * releases the camera.
 *
 * The caller is responsible for the CAMERA runtime permission.
 */
public class QrScanner(context: Context) {

	private val appContext: Context = context.applicationContext

	/**
	 * Emit a [QrScan] for every frame in which a QR code is found.
	 *
	 * Consecutive duplicate detections are not suppressed — apply
	 * `.distinctUntilChanged()` or `.take(1)` to taste.
	 */
	public fun codes(preview: PreviewView, owner: LifecycleOwner): Flow<QrScan> = callbackFlow {
		val provider = awaitCameraProvider()
		val executor = Executors.newSingleThreadExecutor { r ->
			Thread(r, "Read3r-qr-analyzer").apply { isDaemon = true }
		}
		val decoder = QrDecoder()

		val previewUseCase = Preview.Builder().build().apply {
			setSurfaceProvider(preview.surfaceProvider)
		}
		val analysis = ImageAnalysis.Builder()
			.setBackpressureStrategy(ImageAnalysis.STRATEGY_KEEP_ONLY_LATEST)
			.build()
			.apply {
				setAnalyzer(executor) { image ->
					image.use { frame ->
						decodeFrame(decoder, frame)?.let { trySend(it) }
					}
				}
			}

		provider.unbindAll()
		provider.bindToLifecycle(
			owner, CameraSelector.DEFAULT_BACK_CAMERA, previewUseCase, analysis,
		)

		awaitClose {
			analysis.clearAnalyzer()
			provider.unbindAll()
			executor.shutdown()
		}
	}

	private suspend fun awaitCameraProvider(): ProcessCameraProvider =
		suspendCancellableCoroutine { cont ->
			val future = ProcessCameraProvider.getInstance(appContext)
			future.addListener({
				try {
					cont.resume(future.get())
				} catch (t: Throwable) {
					cont.resumeWithException(t)
				}
			}, ContextCompat.getMainExecutor(appContext))
		}

	private fun decodeFrame(decoder: QrDecoder, image: ImageProxy): QrScan? {
		val media = image.image ?: return null
		if (media.format != ImageFormat.YUV_420_888) return null
		val plane = media.planes[0]
		val luma = packLuminance(plane.buffer, plane.rowStride, image.width, image.height)
		val code = decoder.decode(luma, image.width, image.height) ?: return null
		return QrScan(code, image.imageInfo.rotationDegrees)
	}

	/** CameraX rows are padded to rowStride; ZXing needs them packed. */
	private fun packLuminance(src: ByteBuffer, rowStride: Int, width: Int, height: Int): ByteArray {
		val out = ByteArray(width * height)
		if (rowStride == width) {
			src.get(out, 0, minOf(out.size, src.remaining()))
			return out
		}
		val row = ByteArray(rowStride)
		var offset = 0
		for (y in 0 until height) {
			src.position(y * rowStride)
			src.get(row, 0, minOf(rowStride, src.remaining()))
			row.copyInto(out, offset, 0, width)
			offset += width
		}
		return out
	}
}
```

   * Scans as a cold [Flow], with the lock-on animation applied before each
   * emission.

   * when collection begins and releases when it ends. Collect inside

   * The host is responsible for the CAMERA runtime permission; without it
   * CameraX fails to bind and the failure arrives through the Flow.

1. **Injectable `SecureRandom` in `Bac`.** Without it the EXTERNAL AUTHENTICATE command bytes vary per run, so the BAC happy path cannot be transcript-tested end-to-end. Task 6 tests the failure paths only. Worth doing next.
2. **Real captured transcripts.** Every fixture in this plan is synthetic and marked as such. A synthetic transcript encodes the implementation's assumptions, not the card's behaviour.
3. **Progress reporting** (spec decision D2). A ~4-second passport read shows one spinner. Addable later as a `read(tag, key, progress)` overload — source- and binary-compatible.
4. **A BOM artifact.** Eight artifacts must stay version-aligned; a single `VERSION_NAME` and always releasing together is the current mitigation.
5. **Compose wrappers.** The `Flow` is Compose-friendly already.
6. **`:qr-view` as a ninth artifact.** A headless consumer currently pays for ~660 lines of `Canvas` code. Splitting it out later is additive.
